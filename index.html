Game Audio · FMOD & Unity

Interactive Sound Worlds

Responsive audio systems connecting player input / character status / changes in the game world

View Details ↗

Brake!!! is a game designed in a game gem with a theme of emotion - how emotion drives consequences. This game, through its gameplay mechanism, visual design, and audio system, bridge player's vision and auditory system together to simulate the "stress" when driving. The whole game is controled by one button (RT on external controller, space bar on computer - note controller allow for gradually brake) to brake the car. The music and surrounding sounds are changed according to the car's speed, and stress meter.

Role
Sound designer · Music Composer · Audio implementer
