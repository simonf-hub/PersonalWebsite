# Simon Fang — Audio Portfolio

This package contains the complete static website.

## Pages

- `index.html` — home
- `portfolio.html` — filterable project portfolio
- `process.html` — behind-the-scenes workflow

## Shared files

- `styles.css` — main visual system and responsive layouts
- `subpages.css` — portfolio and process page styles
- `script.js` — navigation, filters, project dialogs, and interactive waveform

Open `index.html` in a browser to view the site locally. Keep all files in the same folder so navigation and styling continue to work.
